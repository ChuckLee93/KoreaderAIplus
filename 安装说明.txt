KOAI —— Kindle KOReader AI 阅读助手（v2.7.5）
安装说明

═════════════ 这是什么 ═════════════

KOReader 的 AI 阅读助手插件，仅用 DeepSeek，需自备 API Key。
获取 Key：https://platform.deepseek.com 注册 → 实名 → 创建 API Key → 充值（10 元可用很久）。

两种模式，一套插件：
· 轻量模式（默认）：划词即问即答，启动只加载最小模块，不自动联网、不费 token。
· 精读模式（默认关）：大部头专用，读时临时打开，见《使用说明》。

日常怎么用（模式切换、人物别名、常见问题等）请看同文件夹的《使用说明》。

═════════════ 安装 ═════════════

1. 设备连电脑，把本文件夹的 koai.koplugin 整个复制到 koreader/plugins/ 下；
2. 记事本打开 koai.koplugin/ai_query.lua，把顶部 local API_KEY = "输入API密钥"
   引号里换成自己的 Key，保存；
3. 重启 KOReader。日后换 Key 也只改这一处。

※ 本文件夹不含任何 API Key（仅占位符）；填好 Key 的文件勿外传。
※ 升级安装：用本文件夹的 koai.koplugin 覆盖 koreader/plugins/ 下的同名文件夹即可，
  规则/档案/缓存都在 KOReader 数据目录里，不受影响。覆盖后必须彻底退出 KOReader
  再重进（Lua 模块有进程缓存）。

免责声明：本插件仅供学习交流，请自行遵守 DeepSeek 及模型服务商的使用条款。
